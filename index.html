📄 Publication2026

Evidence-Gated Memory Writing for Personalized Large Language Model Agents

Personalized agents often write every detail to long-term memory, which pollutes it over time. This paper proposes the Evidence-Gated Memory Writer (EGMW), a gate that runs before anything is saved. It scores each candidate memory on long-term usefulness, consistency with what the agent already remembers, and whether there is enough evidence. Only well-supported memories are kept. The paper compares EGMW with four memory-writing strategies.

📄 Publication2026

MemWeave: An Adaptive Framework for Long-Term Agent Knowledge Management via Unified Graph and Vector Memory

Long-running agents need two kinds of recall: fuzzy semantic similarity and explicit relationships between facts. MemWeave keeps a semantic vector memory and a relational graph memory side by side. An adaptive Memory Router sends each query to vector retrieval, graph traversal or a hybrid of both.

MediumOct 2026

AI Agents Are Starting to Look a Lot Like Software Systems

Tools still need schemas and error handling. "Memory" is context, state, storage and retrieval. Harnesses still need observability. The new part is a probabilistic decision-maker inside the system, which raises the question: what should the model reason about, and what should software control? My take is that production agents are probabilistic reasoning embedded in deterministic infrastructure.
